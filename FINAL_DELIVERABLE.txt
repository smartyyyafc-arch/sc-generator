HOW IT WORKS
============

1. ENCODING PHASE
   Command: "powershell.exe -NoProfile -Command \"Write-Host 'Test'\""
   Hex: "706f7765727368656c6c2e657865202d4e6f50726f66696c65202d436f6d6d616e64202257726974652d486f737420275465737427"
   (Each byte converted to 2-character hex representation)

2. DECODING PHASE
   Function DecodeHex loops through hex string 2 characters at a time:
   "70" → CLng("&H70") → 112 → Chr(112) → "p"
   "6F" → CLng("&H6F") → 111 → Chr(111) → "o"
   "77" → CLng("&H77") → 119 → Chr(119) → "w"
   (Continue for entire string)
   Result: Original command string reconstructed

3. EXECUTION PHASE
   CreateObject("WScript.Shell") → Create Windows Script Host shell
   .Run(command, 0, False) → Execute command
     • 0 = Hidden window (invisible)
     • False = Non-blocking (async)
   Set = Nothing → Release COM object
