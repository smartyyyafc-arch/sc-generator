================================================================================
KNOWN LIMITATIONS
================================================================================

HEX DECODER:
❌ No built-in integrity checking
❌ Patterns visible to static analysis
❌ No anti-analysis protection
→ Mitigation: Add obfuscation layer

BASE64 DECODER:
❌ HMAC verification adds 30-50ms overhead
❌ Requires Python runtime
❌ Cannot run in pure VBS environment
→ Mitigation: Acceptable for most deployments

ARRAY DECODER:
❌ Large VBS files (10-20KB)
❌ Requires VBS/WScript runtime
❌ Anti-debug only effective on Windows
❌ Slower execution (100ms-5s)
→ Mitigation: Worth the performance cost for evasion needs
