Encoding Algorithm:
  Input:    ASCII command string
  Output:   Hexadecimal string (2 chars per ASCII char)
  Method:   Python str.encode().hex()
  Example:  "cmd" → "636d64"

Decoding Algorithm:
  Input:    Hexadecimal string
  Loop:     For i = 1 To Len(hex) Step 2
  Extract:  Mid(hex, i, 2) → 2-char hex pair
  Convert:  CLng("&H" + pair) → decimal integer
  Char:     Chr(decimal) → ASCII character
  Result:   Accumulated decoded string
  Output:   Original ASCII command string
