VARIANT 1: COMMANDDECODER
================================================================================

Purpose:         Shell commands (cmd.exe, powershell.exe)
Optimization:    ASCII fast path (0x20-0x7E)
Execution:       Direct WScript.Shell.Run()
Code Size:       ~500-700 bytes
Temp Files:      None required

Key Features:
  ✓ Fast path for printable ASCII characters
  ✓ Direct command execution without file I/O
  ✓ Minimal code overhead
  ✓ Randomized variable names
  ✓ Single-line execution

Use Cases:
  • PowerShell one-liners
  • Cmd.exe commands
  • Single-line shell commands
  • Fast execution payloads
  • Minimal code size requirements

Method Signature:
  vbs_code, metadata = HexDecoderVariants.create_command_decoder(
      command: str,
      execute: bool = True
  )

Example:
  cmd = "powershell.exe -NoProfile -Command 'Write-Host Test'"
  vbs, meta = HexDecoderVariants.create_command_decoder(cmd, execute=True)
  # Result: ~950 bytes total, command decoded and executed immediately

Performance:
  • Encoding: O(n) linear
  • Decoding: O(n) with ASCII fast path
  • Execution: Immediate via Shell.Run()

VARIANT 2: SCRIPTDECODER
================================================================================

Purpose:         VBScript, batch, PowerShell scripts
Optimization:    Full character support with control sequences
Execution:       cscript.exe via temporary file
Code Size:       ~800-1200 bytes
Temp Files:      Yes (auto-deleted)

Key Features:
  ✓ Full ASCII character support (0x00-0xFF)
  ✓ Special handling for CR (0x0D), LF (0x0A), Tab (0x09)
  ✓ Temporary file creation in %TEMP%
  ✓ Execution via cscript.exe subprocess
  ✓ Automatic file deletion after execution
  ✓ Preserves multi-line script formatting

Use Cases:
  • Multi-line VBScript payloads
  • Batch scripts (.bat, .cmd)
  • PowerShell scripts with formatting
  • Complex command sequences
  • Scenarios requiring auto-cleanup
  • Execution isolation via subprocess

Method Signature:
  vbs_code, metadata = HexDecoderVariants.create_script_decoder(
      script_content: str,
      execute: bool = True
  )

Example:
  script = """
  Set objShell = CreateObject("WScript.Shell")
  objShell.Run "notepad.exe"
  """
  vbs, meta = HexDecoderVariants.create_script_decoder(script, execute=True)
  # Result: ~1.6 KB, creates temp file, executes, auto-cleans

Performance:
  • Encoding: O(n) linear
  • Decoding: O(n) with Select/Case branching
  • File Write: Sequential via FileSystemObject
  • Execution: Via cscript.exe subprocess
  • Cleanup: Automatic DeleteFile

Temp File Handling:
  • Location: %TEMP%\tmpRANDOM.vbs
  • Created via: fso.CreateTextFile()
  • Executed via: Shell.Run("cscript.exe " & file)
  • Deleted via: fso.DeleteFile()

VARIANT 3: BINARYDECODER
================================================================================

Purpose:         Binary executables, DLLs, raw binary data
Optimization:    Byte array with integrity verification
Execution:       Direct execution via temporary file
Code Size:       ~600-900 bytes
Temp Files:      Yes (auto-deleted)

Key Features:
  ✓ Byte array allocation and population
  ✓ Full 0x00-0xFF byte value support
  ✓ Integrity verification (size check)
  ✓ ADODB.Stream for safe binary I/O
  ✓ Binary mode (Type = 1) to prevent encoding
  ✓ Direct binary execution or RunDLL32 compatible
  ✓ Automatic temporary file cleanup
  ✓ No encoding loss for binary data

Use Cases:
  • PE executables (.exe, .dll)
  • Compiled binary payloads
  • Data requiring integrity verification
  • Binary content with null bytes (0x00)
  • RunDLL32 compatible payloads
  • Scenarios where encoding might corrupt data

Method Signature:
  vbs_code, metadata = HexDecoderVariants.create_binary_decoder(
      binary_data: Union[bytes, str],
      execute: bool = True
  )

Example:
  with open("payload.exe", "rb") as f:
      binary = f.read()
  vbs, meta = HexDecoderVariants.create_binary_decoder(binary, execute=True)
  # Result: Integrity verified, binary preserved, direct execution

Performance:
  • Encoding: O(n) linear
  • Decoding: O(n) with array allocation
  • File Write: ADODB.Stream (efficient binary I/O)
  • Integrity Check: O(1) array bounds verification
  • Execution: Direct via Shell.Run()

Binary File Handling:
  • Location: %TEMP%\binRANDOM.exe
  • Written via: ADODB.Stream in binary mode
  • Verification: UBound(array) + 1 == expected_size
  • Executed via: Shell.Run(file)
  • Deleted via: fso.DeleteFile()

Integrity Verification:
  If UBound(byteArray) + 1 <> EXPECTED_SIZE Then
      WScript.Echo "Binary integrity check failed"
      WScript.Quit 1
  End If

================================================================================
METADATA STRUCTURE
================================================================================

All variants return a dictionary with generation details:

COMMON FIELDS:
  • type: 'command', 'script', or 'binary'
  • function_name: Generated decoder function name
  • hex_var: Variable holding hex string
  • payload_type: Human-readable payload type
  • encoding: 'hex'
  • optimization: Optimization strategy used
  • hex_length: Length of hex string
  • execute: Boolean whether execution code included

COMMAND-SPECIFIC:
  • decoded_var: Variable holding decoded command
  • shell_var: WScript.Shell variable (if execute=True)
  • command_length: Original command length

SCRIPT-SPECIFIC:
  • decoded_var: Variable holding decoded script
  • shell_var: WScript.Shell variable (if execute=True)
  • script_length: Original script length
  • execution_method: 'cscript.exe via temporary file' (if execute=True)

BINARY-SPECIFIC:
  • decoded_array: Variable holding byte array
  • file_var: Temp file path variable (if execute=True)
  • shell_var: WScript.Shell variable (if execute=True)
  • binary_length: Size in bytes
  • execution_method: 'Direct execution via temporary file' (if execute=True)
  • integrity_check: 'Expected N bytes'
