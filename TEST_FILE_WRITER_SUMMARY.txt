WHAT IS IT?
================================================================================

TestFileWriter is a comprehensive testing framework that automates the full
lifecycle of test execution:

  1. WRITE    → Write payload to test file
  2. VERIFY   → Verify file integrity with SHA256 hashing
  3. EXECUTE  → Run the test with automatic interpreter detection
  4. CLEANUP  → Remove temporary files
  5. REPORT   → Return detailed results

CORE FEATURES
================================================================================

✓ Payload Writing

  - SHA256 integrity hashing

ERROR CODES
================================================================================

Exit Status:
  0 - All tests passed
  1 - One or more tests failed

Test Status Values:
  SUCCESS  - Execution successful (exit code 0)
  FAILED   - Execution failed (exit code != 0)
  ERROR    - Execution error (exception)
  TIMEOUT  - Execution timed out
  SKIPPED  - Test was skipped

CI/CD INTEGRATION
================================================================================

Example integration:

  import json
  import sys
  from test_file_writer import TestFileWriter, generate_summary

  writer = TestFileWriter(verbose=False)
  results = writer.run_multiple_tests(test_cases)
  summary = generate_summary(results)

  # Save results
  with open('test_results.json', 'w') as f:
      json.dump({'summary': summary, 'results': [r.to_dict() for r in results]}, f)

  # Report
  print(f"Passed: {summary['passed']}/{summary['total_tests']}")

  # Exit with proper code
  sys.exit(0 if summary['failed'] == 0 else 1)
