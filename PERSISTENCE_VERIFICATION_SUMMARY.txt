PRIMARY PERSISTENCE: Registry (Windows)
├─ Hive: HKEY_CURRENT_USER (HKCU)
├─ Path: Software\Microsoft\Windows\CurrentVersion\Run
├─ Type: REG_SZ
├─ Advantages:
│  - No admin privileges required
│  - User-specific, isolated
│  - Survives system updates
│  - Lower detection risk
└─ Disadvantages:
   - Lost when user account deleted
   - Visible in user registry

FALLBACK PERSISTENCE: Registry (System-wide)
├─ Hive: HKEY_LOCAL_MACHINE (HKLM)
├─ Path: Software\Microsoft\Windows\CurrentVersion
├─ Type: REG_SZ
├─ Requirements: Admin/SYSTEM privileges
├─ Advantages:
│  - System-wide persistence
│  - Survives user logout
│  - Larger storage capacity
└─ Disadvantages:
   - Requires admin privileges
   - More monitored

SECONDARY PERSISTENCE: Environment Variables
├─ Scope: USER (environment variables)
├─ Platforms: Windows, Linux, macOS
├─ Write Methods:
│  - Windows: setx command or Registry

│  - macOS: .zshrc/.bash_profile modification
├─ Advantages:
│  - Cross-platform support
│  - Process inheritance
│  - No special privileges needed
└─ Disadvantages:
   - Process-level scope
   - Temporary (unless persisted)

TERTIARY PERSISTENCE: File Backup
├─ Location: Temporary directory
├─ Method: File system storage
├─ Advantages:
│  - Universal fallback
│  - Works everywhere
│  - No special requirements
