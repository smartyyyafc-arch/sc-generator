================================================================================
API METHODS (10+)
================================================================================

PRIMARY METHODS:

generate_event_subscription_vbs(command, trigger_type)
  - Basic event subscription creation
  - Configurable WMI event trigger
  - Returns VBS payload

generate_timer_event_consumer(command, interval_milliseconds)
  - Periodic execution via timer events
  - Precise timing intervals
  - Returns VBS payload

generate_service_startup_consumer(command, service_name)
  - Trigger on service startup
  - Specify which service to monitor
  - Returns VBS payload

generate_event_trigger_subscription(command, process_name)
  - Execute on specific process launch
  - Monitor single process
  - Returns VBS payload

generate_async_event_handler(command)
  - Asynchronous class-based handler
  - Non-blocking event handling
  - Returns VBS payload

generate_encoded_event_subscription(command, trigger_type, encoding)
  - Encode command (Base64/Hex)
  - Support both VBS and alternative encodings
  - Returns VBS payload with decoder

generate_powershell_event_subscription(command, trigger_type)
  - PowerShell-based implementation
  - Alternative to VBS
  - Returns PowerShell payload

generate_event_subscription_removal(filter_name, consumer_name)
  - Cleanup subscriptions
  - Remove all traces
  - Returns cleanup VBS payload

HIGH-LEVEL API:

generate_event_subscription_payload(command, event_type, **kwargs)
  - Unified interface for all subscription types
  - Supports: process, service, timer, trigger, encoded, async, powershell
  - Returns appropriate payload type

CONFIGURATION:

EventSubscriptionConfig(...)
  - event_trigger: EventTriggerType (default: PROCESS_START)
  - event_filter_name: str (default: "AutoStartEvent")
  - consumer_name: str (default: "CommandConsumer")
  - namespace: str (default: "root\\subscription")
  - obfuscate_names: bool (default: True)
  - hide_errors: bool (default: True)
