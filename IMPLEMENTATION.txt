WMI PROCESS EXECUTION VIA WIN32_PROCESS - IMPLEMENTATION SUMMARY
================================================================================

OVERVIEW:
---------
WMI (Windows Management Instrumentation) provides process execution through
Win32_Process.Create() method with parameter encoding to avoid detection.

================================================================================
PARAMETER ENCODING METHODS:
================================================================================

METHOD 1: BASE64 ENCODING
Usage: Converts command to Base64 to hide actual command
Signature: powershell.exe -NoProfile -EncodedCommand [BASE64]

METHOD 2: POWERSHELL -ENCODEDCOMMAND
Usage: UTF-16LE encoding required by PowerShell's native parameter
Signature: powershell.exe -EncodedCommand [UTF16LE_BASE64]

METHOD 3: HEX ENCODING
Usage: Encodes command as hexadecimal for runtime interpretation
Signature: powershell.exe -Command "[System.Text.Encoding]::ASCII.GetString()"

METHOD 4: CAESAR CIPHER
Usage: Simple substitution cipher with configurable shift
Signature: Shift each character by N positions in alphabet

METHOD 5: ENVIRONMENT VARIABLES
Usage: Store command segments in environment variables
Signature: %VAR_NAME% at runtime

================================================================================
WIN32_PROCESS.CREATE SIGNATURE:
================================================================================

Return Values:
- 0: Success
- 2: Access Denied
- 3: Insufficient Privilege
- 8: Unknown Failure
- 9: Path Not Found
- 21: Invalid Parameter

Parameters:
- CommandLine: Full command to execute
- CurrentDirectory: Working directory (optional)
- ProcessStartupConfig: Startup configuration object
