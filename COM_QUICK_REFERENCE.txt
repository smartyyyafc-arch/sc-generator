CORE INSTANTIATION METHODS:
================================================================================

1. CreateObject (ProgID)
   Syntax: Set obj = CreateObject("Excel.Application")
   Use: Most common, standard automation
   Detection: Easy - ProgID string visible
   Speed: Medium

2. CreateObject (CLSID)
   Syntax: Set obj = CreateObject("CLSID:{00024500-0000-0000-C000-000000000046}")
   Use: Obfuscation, bypass ProgID detection
   Detection: Harder - GUID only
   Speed: Slightly Faster

3. GetObject (Running)
   Syntax: Set obj = GetObject(, "Excel.Application")
   Use: Stealth - reuses existing process
   Detection: Moderate
   Speed: Fast (if exists)

4. GetObject (Moniker)
   Syntax: Set obj = GetObject("C:\file.doc")
   Use: File-based object binding
   Detection: Moderate
   Speed: Medium

5. GetObject (WMI)
   Syntax: Set obj = GetObject("winmgmts://./root/cimv2")
   Use: Direct WMI namespace access
   Detection: Moderate
   Speed: Medium

6. New Keyword
   Syntax: Set obj = New Excel.Application
   Use: Early binding (requires library reference)
   Detection: Easy
   Speed: Fast

7. CreateObject (Remote DCOM)
   Syntax: Set obj = CreateObject("Excel.Application", "192.168.1.100")
   Use: Remote system access
   Detection: Hard (network traffic)
   Speed: Slow

8. Registry Lookup
   Syntax: clsid = shell.RegRead("HKCR\ProgID\CLSID\")
           Set obj = CreateObject("CLSID:" & clsid)
   Use: Dynamic CLSID resolution
   Detection: Moderate
   Speed: Slow

9. WMI Class Instantiation
   Syntax: Set svc = locator.ConnectServer(".", "root\cimv2")
           Set cls = svc.Get("Win32_Process")
   Use: WMI class-based execution
   Detection: Hard
   Speed: Medium

OBFUSCATION TECHNIQUES:

1. Base64 Encoding
   Function: DecodeBase64(encoded)
   Decoder: MSXML2.DOMDocument
   Example: CreateObject(DecodeBase64("V1NjcmlwdC5TaGVsbA=="))

2. Hex Encoding
   Function: DecodeHex(hexStr)
   Method: Chr() with hex characters
   Example: CreateObject(DecodeHex("57536372697074..."))

3. CLSID Moniker
   Syntax: GetObject("new:{CLSID}")
   Example: GetObject("new:{F935DC22-1CF0-11D0-ADB9-00C04FD58A0B}")

4. Inline Class
   Method: Define VBScript class inline
   Example: Class FakeObj ... End Class
            Set obj = New FakeObj

Function DecodeBase64(encoded)
    Dim xmlDoc, node
    Set xmlDoc = CreateObject("MSXML2.DOMDocument")
    Set node = xmlDoc.CreateElement("tmp")
    node.DataType = "bin.base64"
    node.Text = encoded
    DecodeBase64 = node.NodeTypedValue
End Function
Set shell = CreateObject(DecodeBase64("V1NjcmlwdC5TaGVsbA=="))
