KEY FEATURES
================================================================================

EVENT-DRIVEN ASYNCHRONOUS EXECUTION
- Commands execute automatically when WMI events occur
- Non-blocking, event-driven architecture
- No continuous polling required
- Runs in background independent of user session

PERSISTENT EXECUTION
- Subscriptions survive system reboot
- Stored in WMI repository (not filesystem)
- Minimal forensic artifacts
- Legitimate WMI usage patterns

OBFUSCATION & STEALTH

================================================================================
SUPPORTED EVENT SUBSCRIPTIONS
================================================================================

1. BASIC EVENT SUBSCRIPTION
   Method: generate_event_subscription_vbs()
   Trigger: Process/service/system events (configurable)
   Frequency: Event-dependent
   Persistence: Permanent (survives reboot)
   Stealth Level: Very High

2. TIMER-BASED CONSUMER
   Method: generate_timer_event_consumer()
   Trigger: Time interval (milliseconds)
   Frequency: Precise and periodic
   Persistence: Permanent
   Stealth Level: Very High

3. SERVICE STARTUP CONSUMER
   Method: generate_service_startup_consumer()
   Trigger: Specific service startup
   Frequency: Per service restart
   Persistence: Permanent
   Stealth Level: Very High

4. PROCESS-SPECIFIC TRIGGER
   Method: generate_event_trigger_subscription()
   Trigger: Specific process creation
   Frequency: Per process launch
   Persistence: Permanent
   Stealth Level: High

5. ASYNCHRONOUS EVENT HANDLER
   Method: generate_async_event_handler()
   Trigger: Custom async events
   Frequency: Event-dependent
   Persistence: Session-based
   Stealth Level: Very High

6. ENCODED EVENT SUBSCRIPTION
   Method: generate_encoded_event_subscription()
   Trigger: Process/service events
   Encoding: Base64 or Hex
   Persistence: Permanent
   Stealth Level: Maximum

7. POWERSHELL IMPLEMENTATION
   Method: generate_powershell_event_subscription()
   Language: PowerShell instead of VBS
   Trigger: All event types
   Persistence: Permanent
   Stealth Level: Very High

================================================================================
WQL QUERY EXAMPLES
================================================================================

Process Creation:
SELECT * FROM __InstanceCreationEvent
WHERE TargetInstance ISA "Win32_Process"

Service Startup:
SELECT * FROM __InstanceModificationEvent
WHERE TargetInstance ISA "Win32_Service"
AND TargetInstance.State="Running"

Timer Event (60 seconds):
SELECT * FROM __TimerEvent
WHERE TimerInterval=60000

User Login:
SELECT * FROM __InstanceCreationEvent
WHERE TargetInstance ISA "Win32_LogonSession"

Registry Change:
SELECT * FROM RegistryKeyChangeEvent
WHERE Hive="HKEY_LOCAL_MACHINE"
