TECHNICAL FEATURES
================================================================================

WMI EXECUTION METHODS (7 Variants)
───────────────────────────────────

1. SWbemLocator Direct Method
   Stealth: ★★★★★ (Very High)
   Speed: Fast
   Key Features:
   - Explicit SWbemLocator connection
   - Direct method invocation
   - Full parameter control
   - Best for local execution

2. SWbem Query Interface
   Stealth: ★★★★☆ (High)
   Speed: Fast
   Key Features:
   - WMI query-based execution
   - Standard WMI interfaces
   - Query parameter handling

3. SWbemObject Method Invocation
   Stealth: ★★★★★ (Very High)
   Speed: Fast
   Key Features:
   - Direct object method calling
   - Parameter spawning
   - ExecMethod invocation

4. WMI Event Sink Execution
   Stealth: ★★★★★ (Very High)
   Speed: Slower (asynchronous)
   Key Features:
   - Asynchronous event handling
   - Event-driven execution
   - Background process capability

5. WMI with Timeout Support
   Stealth: ★★★★☆ (High)
   Speed: Fast
   Key Features:
   - Process timeout management
   - Sleep-based waiting
   - Process monitoring

6. WMI Registry Hybrid
   Stealth: ★★★★☆ (High)
   Speed: Medium
   Key Features:
   - Multi-stage execution
   - Command storage in WMI
   - Base64 encoding/decoding

7. Obfuscated WMI Payload
   Stealth: ★★★★★ (Very High)
   Speed: Fast
   Key Features:
   - Base64 command encoding
   - Hex command encoding
   - Inline decoders
   - Plaintext command hidden

OBFUSCATION FEATURES
────────────────────

1. Variable Name Randomization
   - Random 8-character suffixes on all variables
   - Prevents pattern-based detection
   - Configurable via ExecutionConfig

2. Error Suppression
   - "On Error Resume Next" wrapping
   - Prevents error message alerts
   - Proper error recovery (On Error GoTo 0)

3. Command Encoding
   - Base64 encoding with MSXML decoder
   - Hex encoding with CHR conversion
   - Inline decoder functions
   - Plaintext command never appears

4. Polymorphic Variants
   - 4 different execution patterns
   - Diverse signature generation
   - Same functionality, different code

5. Indirect Instantiation
   - ConnectServer for dynamic connection
   - SpawnInstance_ for object creation
   - Methods_ for method retrieval

PAYLOAD CHARACTERISTICS
──────────────────────

Standard Payload:
  Size: 250-350 bytes
  Structure: Single-stage VBS
  Error Handling: Full
  Variables: Randomized (8 chars)

Obfuscated Payload:
  Size: 400-600 bytes
  Structure: Decoder + execution
  Encoding: Base64 or Hex
  Variables: Randomized (8 chars)

Remote Payload:
  Size: 300-400 bytes
  Structure: Network-aware
  Auth: Credential handling
  Variables: Randomized (8 chars)

Event Sink Payload:
  Size: 350-450 bytes
  Structure: Event handler
  Async: True
  Variables: Randomized (8 chars)
