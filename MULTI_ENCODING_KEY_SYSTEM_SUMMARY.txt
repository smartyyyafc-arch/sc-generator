================================================================================
TECHNICAL ARCHITECTURE
================================================================================

LAYERED DESIGN:
┌─────────────────────────────────────────┐
│  FingerprintKeyIntegration (Facade)    │ ← Unified API
├─────────────────────────────────────────┤
│  MultiEncodingKeySystem (Orchestrator)  │ ← Core system
├─────────────────────────────────────────┤
│  KeyDerivation + Strategy Selection     │ ← Core algorithms
├─────────────────────────────────────────┤
│  FingerprintHasher + Factories          │ ← Utilities
└─────────────────────────────────────────┘

DATA FLOW:
System Fingerprint
        ↓
FingerprintHasher → Deterministic Hash
        ↓
TargetProfile (Configuration)
        ↓
KeyDerivationFactory → Cryptographic Key
        ↓
EncodingStrategySelector → Encoding Parameters
        ↓
DerivedKey + Encoding Strategy
        ↓
Encoded Payload

KEY DERIVATION FLOW:
Fingerprint Data + Salt
        ↓
[PBKDF2|HKDF|Argon2|...]
        ↓
Derived Key (32 bytes default)
        ↓
Convert to Hex / Use in Encoding
        ↓
Store with Metadata

ENCODING FLOW:
Original Payload
        ↓
Select Strategy (HEX|Base64|XOR|...)
        ↓
Apply Strategy with Key
        ↓
Encoded Payload
        ↓
Store with Strategy Info
        ↓
Decode: Reverse Strategy with Same Key

USAGE EXAMPLES
================================================================================

BASIC KEY DERIVATION:
  from multi_encoding_key_derivation import MultiEncodingKeySystem

  system = MultiEncodingKeySystem()
  profile = system.create_target_profile(
      name='Web Server',
      fingerprint_data={'hostname': 'web-01', 'os': 'Linux'}
  )
  derived_key = system.derive_key_for_target(profile.target_id)
  print(derived_key.hex_key)

FINGERPRINT INTEGRATION:
  from fingerprint_key_integration import FingerprintKeyIntegration

  integration = FingerprintKeyIntegration()
  fp_id, target_id = integration.register_fingerprint_with_encoding(
      fingerprint_id='fp_123',
      target_name='Production Target'
  )

  encoded = integration.encode_payload_for_target(
      target_id=target_id,
      payload='secret_message'
  )

MULTI-METHOD COMPARISON:
  from multi_encoding_key_derivation import (
      MultiEncodingKeySystem,
      KeyDerivationMethod
  )

  system = MultiEncodingKeySystem()

  for method in [KeyDerivationMethod.PBKDF2, KeyDerivationMethod.ARGON2]:
      profile = system.create_target_profile(
          name=f'Target {method.value}',
          fingerprint_data={'test': 'data'},
          key_derivation_method=method
      )
      key = system.derive_key_for_target(profile.target_id)
      print(f'{method.value}: {key.hex_key}')
