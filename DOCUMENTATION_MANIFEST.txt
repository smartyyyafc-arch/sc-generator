STORAGE SCOPES:
✓ PROCESS Scope
  * Memory-based (process.env)
  * Temporary persistence (session only)
  * Automatic cleanup
  * Zero detection risk
  * ProcessScopeEnvVarWriter class

✓ USER Scope
  * Windows Registry (HKEY_CURRENT_USER\Environment)
  * Unix Shell RC files (~/.bashrc, ~/.zshrc)
  * Persistent across sessions
  * User-level visibility
  * Moderate detection risk
  * UserScopeEnvVarWriter class

✓ SYSTEM Scope
  * Windows Registry (HKEY_LOCAL_MACHINE)
  * Unix /etc/environment
  * System-wide visibility
  * Requires admin privileges
  * High detection risk
  * NOT RECOMMENDED (documented)
  * SystemScopeEnvVarWriter class
