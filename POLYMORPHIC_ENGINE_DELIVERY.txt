================================================================================
ENCODING ALGORITHMS (10 VARIANTS)
================================================================================

1. LINEAR XOR (linear_xor)
   - Random XOR key: 1-255
   - Random offset: 0-255
   - Formula: encoded = ((byte ^ key) + offset) & 0xFF
   - Size: ~530 bytes
   - Speed: Extremely fast

2. BITWISE ROTATION (bitwise_rot)
   - Rotation amount: 1-7 bits
   - Formula: encoded = ((byte << rot) | (byte >> (8-rot))) & 0xFF
   - Size: ~540 bytes
   - Speed: Very fast

3. MATHEMATICAL OFFSET (math_offset)
   - Multiplier: odd numbers 3-17
   - Shift: 1-256
   - Formula: encoded = (byte * mult + shift) % 256
   - Uses modular inverse for decoding
   - Size: ~550 bytes
   - Speed: Very fast

4. INTERLEAVE REVERSE (interleave_reverse)
   - Splits into even/odd indices
   - Reverses each part separately
   - Re-interleaves differently
   - Size: ~590 bytes
   - Speed: Very fast

5. LOOKUP TABLE (lookup_table)
   - Generates random 256-byte permutation
   - Maps each byte through table
   - Stores reverse lookup for decoding
   - Size: ~1650 bytes (includes full table)
   - Speed: Very fast

6. CHAOTIC SHUFFLE (chaotic_shuffle)
   - Random byte position permutation
   - Stores shuffle indices (8-256 bytes)
   - Inverse permutation applied in decoder
   - Size: ~670 bytes
   - Speed: Very fast

7. WAVE PATTERN (wave_pattern)
   - Random amplitude: 10-50
   - Random frequency: 1-4
   - Adds pseudo-random wave to each byte
   - Size: ~550 bytes
   - Speed: Very fast

8. PRIME MODULO (prime_modulo)
   - Random prime: 2, 3, 5, 7, ..., 71
   - Offset: 1-100
   - Formula: encoded = (byte + offset) % prime
   - Size: ~520 bytes
   - Speed: Very fast

9. FIBONACCI SEQUENCE (fibonacci_sequence)
   - Generates Fibonacci sequence to payload length
   - Adds Fibonacci number to each byte
   - Different sequences each run
   - Size: ~600 bytes
   - Speed: Very fast

10. RECURSIVE SPLIT (recursive_split)
    - Recursively splits data in half
    - Swaps left/right at each level
    - Maximum recursion depth: 3
    - Size: ~500 bytes
    - Speed: Very fast

================================================================================
CONTROL FLOW PATTERNS (4 VARIANTS)
================================================================================

1. SEQUENTIAL
   Direct execution:
   ```
   encoded_X = bytes([...])
   decoded = decode(encoded_X)
   ```

2. CONDITIONAL
   If/else with opaque predicate:
   ```
   if condition_var:
       encoded_X = bytes([...])
       decoded = decode(encoded_X)
   else:
       dummy = None
   ```

3. LOOP
   Wrapped in for loop (executes once):
   ```
   for i in range(1):
       encoded_X = bytes([...])
       decoded = decode(encoded_X)
   ```

4. STATE MACHINE
   Stateful execution pattern:
   ```
   state = 0
   while state == 0:
       encoded_X = bytes([...])
       decoded = decode(encoded_X)
       state = 1
   ```

================================================================================
API REFERENCE
================================================================================

PolymorphicCodeGenerator Methods:

encode_data(data: bytes) -> Tuple[bytes, Dict, str]
  - Encodes data with random algorithm
  - Returns: (encoded_bytes, metadata, algorithm_name)

generate_polymorphic_decoder(encoded_data: bytes, metadata: Dict) -> str
  - Generates Python decoder code
  - Returns: decoder code as string

generate_complete_polymorphic_script(command: str) -> str
  - Generates complete executable script
  - Returns: full Python script with execution

generate_multi_stage_polymorphic(payload: str, stages: int) -> str
  - Generates N-stage polymorphic payload
  - Each stage uses different algorithm
  - Returns: multi-stage Python script

get_generation_info() -> Dict[str, Any]
  - Returns metadata about generated code
  - Keys: algorithm_variants, control_flow_patterns,
          obfuscation_techniques, target_language,
          complexity_level, variables_generated

generate_random_name(prefix: str = "v", length: int = 8) -> str
  - Generates random variable name
  - Returns: unique variable identifier
