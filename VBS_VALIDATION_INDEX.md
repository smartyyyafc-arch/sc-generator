## Files in This Validation Suite

### Core Validation Framework

#### 1. **vbs_syntax_validator.py** (350+ lines)
The heart of the validation system. A comprehensive VBS syntax validator that:

- **Recognizes 50+ built-in VBS functions** across all categories
- **Detects undefined function references** with precise line numbers
- **Validates control structure balance** (If/Next, For/Next, While/Wend, etc.)
- **Handles object methods and COM calls** without false positives
- **Tracks variable declarations** from Dim, Set, and loop statements
- **Distinguishes array subscripts from function calls**
- **Provides detailed error reporting** with context

**Key Classes:**
- `VBSSyntaxValidator` - Main validation engine
- `SyntaxError` - Error representation with line numbers

**Key Methods:**
- `validate(vbs_code)` - Main validation method
- `_collect_declarations()` - First pass: collect all declarations
- `_check_undefined_references()` - Second pass: verify function calls
- `_check_syntax_structure()` - Third pass: validate control structures

**Usage:**
```python
from vbs_syntax_validator import VBSSyntaxValidator
validator = VBSSyntaxValidator()
is_valid, errors = validator.validate(vbs_code)
if is_valid:
    print("VBS code is valid!")
else:
    for error in errors:
        print(f"Line {error.line_number}: {error.message}")
```
