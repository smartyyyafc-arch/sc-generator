OVERVIEW
================================================================================

A comprehensive, redundant persistence system that combines three primary
methods for maximum reliability and evasion:

1. Registry Persistence (Primary)
   - Multiple registry hives (HKCU, HKLM, etc.)
   - Multiple registry paths (Run, RunOnce, Explorer, IE)
   - User/System-level execution
   - Automatic at logon/startup

2. Startup Folder Persistence (Secondary)
   - Multiple file formats (.vbs, .bat, .ps1)
   - Multiple startup locations
   - User-level execution
   - No admin required

3. Scheduled Task Persistence (Tertiary)
   - Multiple trigger types (Logon, Startup, Idle, Network, etc.)
   - System-level execution with elevated privileges
   - Independent of user logon
   - Survives user account changes

4. Fallback Chain (Recovery)
   - Automatic failure detection
   - Re-deployment of failed methods
   - Ensures continuity across cleanup attempts

```python
from advanced_persistence_multimethods import (
    MultiMethodPersistence, PersistenceConfig, RegistryHive
)

config = PersistenceConfig(
    payload="calc.exe",
    use_startup_folder=False,
    use_scheduled_task=False,
    registry_hives=[RegistryHive.HKCU]
)
persistence = MultiMethodPersistence(config)
registry_payloads = persistence.generate_registry_persistence()
```

FULL CONFIGURATION (All Methods):
```python
config = PersistenceConfig(
    payload="powershell.exe -NoProfile -WindowStyle Hidden -Command 'Get-Process'",
    obfuscation_enabled=True,
    obfuscation_level="extreme",
    registry_hives=[RegistryHive.HKCU, RegistryHive.HKLM],
    use_startup_folder=True,
    startup_extensions=[".vbs", ".bat", ".ps1"],
    use_scheduled_task=True,
    task_triggers=[
        ScheduledTaskTrigger.LOGON,
        ScheduledTaskTrigger.STARTUP,
        ScheduledTaskTrigger.INTERVAL

    enable_fallback_chain=True,
    randomize_names=True
```

CLEANUP & REMOVAL
================================================================================

To remove all persistence:

1. Registry Cleanup:
   Delete all registry entries in:
   • HKCU\Software\Microsoft\Windows\CurrentVersion\Run
   • HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce
   • HKCU\Software\Policies\Microsoft\Windows\Explorer
   • HKCU\Software\Microsoft\Internet Explorer\Desktop\Components
   • HKLM\[same paths]

2. Startup Folder Cleanup:
   Delete all scripts from:
   • %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup
   • %ProgramData%\Microsoft\Windows\Start Menu\Programs\Startup
   • C:\Users\Public\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup

3. Scheduled Task Cleanup:
   Delete tasks from Task Scheduler:
   • All custom tasks created
   • Check hidden tasks as well

4. Disable Fallback Chain:
   Remove any fallback recovery mechanisms

NOTE: Complete cleanup requires removing ALL persistence points simultaneously
      to prevent the fallback chain from re-deploying them.
