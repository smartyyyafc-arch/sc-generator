VARIANT GENERATION PROCESS
================================================================================

All variants generated by WMILocatorVariantGenerator class:

GENERATION FLOW:
1. Initialize generator with empty variable cache
2. For each variant type (local/remote/namespace/security):
   a. Generate unique random variable names (8-char suffixes)
   b. Create specific VBS connection code
   c. Embed command to execute
   d. Add error handling
   e. Apply security settings if needed
   f. Return code as string
3. Cache generated code for batch operations
4. Support individual generation or bulk all_variants() call

VARIABLE NAMING:
  • objLoc/objConn/objSvc - Standard names with obfuscation
  • Random suffix generation: v_XXXXXXXX (8 random characters)
  • Consistent naming within variant (cache mechanism)
  • Different names across variant generations

COMMAND EMBEDDING:
  • Plain text: Direct insertion in .Create()
  • Base64: Used for obfuscation in encoded_remote variant
  • Escaping: Backslashes properly escaped for Windows paths
  • Special chars: Handled in quotes

ERROR HANDLING:
  • On Error Resume Next: Suppress errors during execution
  • Object cleanup: Set all objects to Nothing
  • Error reset: On Error GoTo 0 restores normal error handling

SECURITY FEATURES:
  • Impersonation: 0=anonymous, 1=identify, 2=impersonate, 3=delegate
  • Authentication: 4=connect, 5=call, 6=packet, 7=privacy
  • Flags: 128=enable_all_privileges
  • Credentials: Username/password for remote authentication
