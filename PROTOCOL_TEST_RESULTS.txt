CERTIFICATE VALIDATION CHAIN
================================================================================

Step 1: TLS Handshake
  ├─ Client connects to server on port 443
  ├─ Server sends certificate chain
  └─ Python ssl module initiates certificate validation

Step 2: Certificate Verification
  ├─ Signature verification (CA signs certificate)
  ├─ Date validation (not_before <= now <= not_after)
  ├─ CA certificate chain validation (up to root CA)
  └─ Revocation checking (CRL/OCSP)

Step 3: Hostname Matching
  ├─ Extract hostname from URL (example.com)
  ├─ Check certificate CN field
  ├─ Check certificate SAN extension
  ├─ Support wildcard certificates (*.example.com)
  └─ Case-insensitive matching

Step 4: Root CA Trust
  ├─ Verify CA certificate is in trust store
  ├─ Python: certifi library (Mozilla CA bundle)
  ├─ Linux: /etc/ssl/certs/
  └─ Windows: Certificate Store

Result:
  ✓ All checks pass -> Connection established, data transfer secure
  ✗ Any check fails -> SSL exception raised, connection refused

PYTHON DEFAULT BEHAVIOR:
  >>> import ssl, certifi
  >>> context = ssl.create_default_context(cafile=certifi.where())
  >>> context.check_hostname = True
  >>> context.verify_mode = ssl.CERT_REQUIRED
  Result: SECURE by default - all validation enabled

TLS 1.2 Ciphers (LEGACY - IF NEEDED):
  1. ECDHE-ECDSA-AES256-GCM-SHA384    (ECDH key exchange, ECDSA auth)
  2. ECDHE-RSA-AES256-GCM-SHA384      (ECDH key exchange, RSA auth)
  3. ECDHE-ECDSA-CHACHA20-POLY1305    (ChaCha20-Poly1305, ECDSA)
  4. ECDHE-RSA-CHACHA20-POLY1305      (ChaCha20-Poly1305, RSA)

AVOID (WEAK):
  ✗ DES, 3DES (56-bit or 168-bit - breakable in minutes)
  ✗ RC4 (biased byte generation - breakable in hours)
  ✗ MD5 (hash collisions proven)
  ✗ Export-grade (512-bit - breakable in seconds)
  ✗ NULL (no encryption)
  ✗ ANON (no authentication)

Python urllib DEFAULT: Uses only strong ciphers (AES-256, ChaCha20)

IMPLEMENTATION:

    import certifi
    import urllib.request

    context = ssl.create_default_context(cafile=certifi.where())
    context.check_hostname = True
    context.verify_mode = ssl.CERT_REQUIRED

    with urllib.request.urlopen(url, context=context, timeout=30) as r:
        data = r.read()
