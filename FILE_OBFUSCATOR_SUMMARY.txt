================================================================================
                         OBFUSCATION STRATEGIES
================================================================================

Strategy #1: ALTERNATE DATA STREAMS (ADS)
  Platform: Windows NTFS only
  Technique: Hidden data streams invisible to directory listings
  Files Hidden: Yes
  Reversibility: High (requires ADS knowledge)
  Performance: ~10ms
  Advantage: Invisible to casual inspection

Strategy #2: MIXED CASE NAMES
  Platform: All (Windows/macOS/Linux)
  Technique: Randomized filename case combinations
  Files Hidden: Partially (requires mapping)
  Reversibility: High (deterministic with mapping)
  Performance: <1ms
  Advantage: Evades simple pattern matching

Strategy #3: FILE ATTRIBUTES
  Platform: All
  Technique: Hidden (+h) flags (Windows) or dot-prefix (Unix)
  Files Hidden: Yes
  Reversibility: High
  Performance: ~1ms
  Advantage: Hidden from default directory view

Strategy #4: METADATA MANIPULATION
  Platform: All
  Technique: Spoofed timestamps (default: 2020-01-01)
  Files Hidden: No (content visible)
  Reversibility: Moderate (timestamp preserved)
  Performance: ~2ms
  Advantage: Obscures creation/modification time

Strategy #5: DEEP NESTING
  Platform: All
  Technique: 6-level nested directories (configurable)
  Files Hidden: Partially (deep paths)
  Reversibility: Moderate (directory traversal needed)
  Performance: ~5ms
  Advantage: Slows antivirus and scanning tools

Strategy #6: SPECIAL CHARACTERS
  Platform: All
  Technique: Zero-width Unicode characters in filenames
  Files Hidden: Visually (invisible characters)
  Reversibility: Moderate (requires character analysis)
  Performance: ~3ms
  Advantage: Looks normal but technically different

Strategy #7: STEGANOGRAPHY
  Platform: All
  Technique: Embed secret file inside carrier file
  Files Hidden: Yes (invisible embedding)
  Reversibility: High (with carrier size knowledge)
  Performance: ~50ms
  Advantage: Completely invisible, looks innocent

Strategy #8: POLYMORPHIC WRAPPING
  Platform: All
  Technique: Base64, Hex, or Chunked JSON format
  Files Hidden: No (format changed)
  Reversibility: Very High (reversible format)
  Performance: ~10ms
  Advantage: Evades content-based signature detection
