VARIABLE STRUCTURE
------------------
The decoder uses three key variables:

1. hex_var (h_<random>)
   - Stores the hex-encoded command
   - Example: h_NFZemfWA
   - Used in DecodeHex function call

2. decoded_var (decoded_<random>)
   - Stores the decoded command string
   - Example: decoded_eNkURuRQ
   - Assigned from DecodeHex() result
   - Passed to shell.Run()

3. shell_var (shell_<random>)
   - Stores the WScript.Shell object
   - Example: shell_I3X_fcjn
   - Set via CreateObject
   - Calls .Run() method
   - Set to Nothing for cleanup

EXECUTION FLOW
--------------
1. Define DecodeHex(h) function
   ├─ Loops through hex string in pairs
   ├─ Converts each pair to decimal via CLng("&H" + pair)
   └─ Converts decimal to character via Chr()

2. Declare and assign hex variable with encoded payload

3. Declare and assign decoded variable by calling DecodeHex()

4. (If execute=True) Create WScript.Shell and execute
   ├─ Create shell object via CreateObject
   ├─ Call .Run(decoded_var, 0, False)
   │  ├─ 0 = Hidden window style
   │  └─ False = Asynchronous (no wait)
   └─ Clean up with Set object = Nothing

HEX DECODER FUNCTION (DecodeHex):
    Function DecodeHex<random>(h)
        Dim i, r
        For i = 1 To Len(h) Step 2
            r = r & Chr(CLng("&H" & Mid(h, i, 2)))
        Next
        DecodeHex<random> = r
    End Function

How it works:
1. Iterate through hex string 2 characters at a time
2. Extract pair using Mid(h, i, 2)
3. Prepend "&H" to create hex literal (e.g., "&H6E")
4. Convert to decimal using CLng
5. Convert decimal to character using Chr
6. Concatenate all characters to build decoded string
