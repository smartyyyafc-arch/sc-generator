ENCODING PROPERTIES
════════════════════════════════════════════════════════════════════════════════

✓ Deterministic      - Same input always produces same output
✓ Reversible         - Decoding recovers exact original
✓ Lossless           - No information is lost
✓ Idempotent         - Safe to encode/decode multiple times
✓ Unicode-Safe       - Handles emoji and multi-byte UTF-8
✓ Sequential         - Each layer depends on previous
✓ Format-Flexible    - Output available as base64, hex, or array
✓ Hardware-Safe      - No special requirements


TYPICAL USE CASES
════════════════════════════════════════════════════════════════════════════════

1. Config Obfuscation
   Database passwords → Base64 → Hex → Array → Store safely

2. URL Parameters
   User ID + Role → Base64 → Hex → URL-safe parameter

3. API Payloads
   JSON request → Base64 → Hex → Send over network

4. Session Tokens
   Session data → Base64 → Hex → Generate token

5. Data Storage
   Sensitive data → Base64 → Hex → Array → Database


API QUICK REFERENCE
════════════════════════════════════════════════════════════════════════════════

compactMultiEncode(string)     → { base64, hex, array }
compactMultiDecode(encoded)    → string

encodeBase64(string)           → base64_string
decodeBase64(base64_string)    → string

encodeHex(base64_string)       → hex_string
decodeHex(hex_string)          → base64_string

encodeArray(hex_string)        → array_of_hex_pairs
decodeArray(array)             → hex_string

multiEncode(string)            → { base64, hex, array } (with logging)
multiDecode(encoded)           → string (with logging)
