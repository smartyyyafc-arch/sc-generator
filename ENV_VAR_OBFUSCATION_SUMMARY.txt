KEY FEATURES
================================================================================

MULTI-LAYER ENCODING
  • Base64: Standard text encoding
  • Hex: Character codes to hexadecimal (100% size increase)
  • Array: Hex pairs split into chunks
  • Combined: 2.3x original payload size

PAYLOAD SPLITTING
  • Configurable number of chunks (1 to N)
  • Each chunk in separate environment variable
  • Maintains chunk order for reconstruction
  • Supports arbitrary chunk sizes

DECOY INJECTION
  • Injects fake environment variables
  • Mimics real variable structure (hex format)
  • Configurable number of decoys (0 to N)
  • Makes pattern analysis significantly harder
  • Can achieve 70%+ decoy ratio

VARIABLE SHUFFLING
  • Randomizes variable order
  • Maintains order info in separate field
  • Defeats order-based detection
  • Millisecond-level overhead

RECONSTRUCTION LOGIC
  • Self-contained JavaScript function
  • Can be injected into target environment
  • Filters out decoy variables automatically
  • Reverses all encoding layers
  • No external dependencies

API SUMMARY
================================================================================

Constructor:
  new EnvVarObfuscator(options)
    - chunkSize: (optional) manual chunk size
    - numChunks: (optional) default chunks (default: 4)

Main Method:
  obfuscate(payload, options)
    - chunks: number of env vars (default: 4)
    - addDecoys: add fake vars (default: true)
    - numDecoys: number of decoys (default: 3)
    - prefix: variable name prefix (default: 'OBF')
    - shuffle: randomize order (default: true)

    Returns: {
      variables: {},           // All obfuscated variables
      varNames: [],           // All var names (shuffled)
      dataVarNames: [],       // Data vars only (correct order)
      reconstructor: "code",  // JavaScript function
      metadata: {}            // Encoding information
    }

Helper Methods:
  multiEncode(payload)                 // Base64 → Hex → Array
  multiDecode(encodedData)             // Reverse process
  reconstructFromEnv(env, varNames)    // Reconstruct from env vars
  generateShellExport(variables)       // Bash export script
  generateReport(payload, result)      // Comprehensive report
