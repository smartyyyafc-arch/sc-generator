KEY FEATURES
================================================================================

1. Version Detection
   - Detects Windows version at runtime via WMI
   - Generates VBScript code for version checking
   - Handles version parsing (including three-part versions)

2. UAC-Aware Instantiation
   - Windows XP: Direct access (no UAC)
   - Windows Vista+: UAC context detection
   - Integrity level awareness

3. Registry Path Variants
   - Version-specific registry paths
   - COM object registration paths
   - AppData location registry entries
   - Windows Run keys (HKCU, HKLM)

4. AppData Folder Handling
   - Windows XP: Documents and Settings\%USERNAME%
   - Windows Vista+: Users\%USERNAME%\AppData
   - Automatic path expansion
   - Folder existence checking

5. COM Object Availability
   - Version-specific COM object databases
   - Availability checking functions
   - Fallback mechanisms
   - Application installation detection

6. Security Features Awareness
   - UAC (User Account Control)
   - ASLR (Address Space Layout Randomization)
   - DEP/NX (Data Execution Prevention)
   - Code Integrity (CI)
   - AppContainer isolation
   - Virtualization-Based Security (VBS)
   - Credential Guard
   - Secure Boot

7. Fallback Cascades
   - Multi-version fallback chains
   - Tries newer versions first
   - Graceful degradation
   - Success tracking

8. Version-Optimized Variants
   - Performance optimization (minimal overhead)
   - Stealth optimization (minimize detection)
   - Compatibility optimization (maximum support)

================================================================================
DEPRECATION & LEGACY SUPPORT
================================================================================

Windows XP (End of Life)
- No longer actively developed
- Limited COM object support
- No ASLR/integrity levels
- Still supported by this module

Windows Vista (Extended Support Ending)
- UAC introduction
- Some legacy COM objects require elevation
- Registry virtualization active

Windows 7 (Mainstream Support Ended)
- Stable version
- Full COM support
- Common in corporate environments

Windows 8 (Mainstream Support Ended)
- Metro/Desktop app split
- Some COM access restrictions in Store apps

Windows 10 (LTS Until 2025)
- Active support
- VBScript still supported (deprecated)
- Comprehensive COM support

Windows 11 (Current)
- Latest security features
- VBScript removed from Group Policy
- Most restrictive COM access
- Signed driver requirement

================================================================================
TROUBLESHOOTING GUIDE
================================================================================

Problem: COM Object Not Available
Solution: Check available_com_objects list, use fallback cascade

Problem: Registry Access Denied
Solution: Non-elevated process has virtualized registry, use fallback paths

Problem: VBScript Not Executing (Win11)
Solution: VBScript removed from Group Policy, use PowerShell alternative

Problem: Integrity Level Problems
Solution: Check UAC/Integrity Control features, use elevation if required

Problem: COM Object Requires Elevation
Solution: Request UAC prompt or run with admin privileges
