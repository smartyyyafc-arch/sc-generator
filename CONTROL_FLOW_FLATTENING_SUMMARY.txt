KEY FEATURES IMPLEMENTED
================================================================================

1. CONTROL FLOW FLATTENING
   ├─ Converts nested control structures to state machines
   ├─ Extracts conditionals from if/else chains
   ├─ Linearizes branching logic
   ├─ Creates switch-based dispatch system
   └─ Maintains semantic equivalence

2. POLYMORPHIC STATE REPRESENTATIONS (5 modes)
   ├─ NUMERIC: Integer states (minimal overhead)
   ├─ STRING: Character-encoded states
   ├─ OBJECT: Object-based states with decoys
   ├─ ARRAY: Array-indexed states
   └─ COMPUTED: Opaque arithmetic expressions

3. OPAQUE PREDICATES
   ├─ Always-true: !(1 === 0), Math.abs(-1) === Math.abs(1)
   ├─ Always-false: (1 === 0), (NaN === NaN)
   ├─ Ambiguous: Bitwise operations with random values
   ├─ Hard to simplify through static analysis
   └─ Multiple techniques to evade detection

4. ANTI-ANALYSIS FEATURES
   ├─ Dead Code Insertion: Unreachable code paths
   ├─ Junk State Insertion: Fake state transitions
   ├─ State Reordering: Non-sequential state numbers
   ├─ Variable Encoding: Randomized variable names
   └─ Condition Obfuscation: Wrapped with meaningless checks

5. CODE GENERATION
   ├─ Function signature parsing
   ├─ Control structure extraction
   ├─ State machine generation
   ├─ Complete function wrapping
   └─ Configurable feature sets

USAGE EXAMPLES

EXAMPLE 1: Basic Usage
────────────────────

const { FlattenedCodeGenerator, PolymorphicState } = require('./control-flow-flattening');

function myFunc(x) {
  if (x > 0) return x * 2;
  else return x * 3;
}

const generator = new FlattenedCodeGenerator();
const code = generator.generateCompleteFunction(myFunc, 'obfuscated', {
  polymorphicMode: PolymorphicState.MODES.COMPUTED,
  opaquePredicates: true
});

EXAMPLE 2: Multiple Modes
──────────────────────────

const modes = [
  PolymorphicState.MODES.NUMERIC,     // Fastest
  PolymorphicState.MODES.OBJECT,      // Balanced
  PolymorphicState.MODES.COMPUTED     // Most secure
];

modes.forEach(mode => {
  const code = generator.generateFromFunction(func, {
    polymorphicMode: mode
  });
  console.log(code);
});

EXAMPLE 3: Selective Features
──────────────────────────────

// Performance-optimized
const fastCode = generator.generateFromFunction(func, {
  polymorphicMode: 'numeric',
  opaquePredicates: false,
  deadCode: false
});

// Maximum security
const secureCode = generator.generateFromFunction(func, {
  polymorphicMode: 'computed',
  opaquePredicates: true,
  deadCode: true,
  junkStates: true,
  stateReordering: true
