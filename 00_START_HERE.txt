CODE EXAMPLES

WScript.Shell (Simple):
  Set objShell = CreateObject("WScript.Shell")
  objShell.Run "cmd.exe /c whoami", 0, False
  Set objShell = Nothing

WMI (Secure):
  Set locator = CreateObject("WbemScripting.SWbemLocator")
  Set conn = locator.ConnectServer(".", "root\cimv2")
  Set service = conn.Get("Win32_Process")
  Set method = service.Methods_("Create")
  Set inParams = method.InParameters.SpawnInstance_()
  inParams.CommandLine = "cmd.exe /c whoami"
  conn.ExecMethod "Win32_Process", "Create", inParams

FREQUENTLY ASKED QUESTIONS
================================================================================

Q: Which method should I use?
A: Depends on priority. Speed? Use WScript.Shell. Stealth? Use WMI.
   Best? Use hybrid approach with both.

Q: Why is WMI so much slower?
A: WMI requires connecting to WMI service, resolving classes, binding methods,
   creating parameter objects. This overhead is 2.64x vs direct COM calls.

Q: Is WMI really more stealthy?
A: Yes, 30-50% detection likelihood vs 80-95% for WScript.Shell.
   Detection is harder because WMI mimics legitimate admin tools.

Q: What's the detection risk if I use WScript.Shell?
A: HIGH (80-95%). Easy to detect by AV/EDR. Not suitable for monitored
   environments unless stealth is not a concern.

Q: Can I make WScript.Shell stealthier?
A: Only marginally. String obfuscation doesn't help much. Behavioral
   detection will still catch it. Better to use WMI.

Q: What's the overhead of using a hybrid approach?
A: Minimal. You get ~290ms for stealth path, ~110ms for speed fallback.
   Polymorphic switching adds negligible overhead.

Q: Is the 2.64x gap consistent?
A: Yes, maintained across all batch sizes (1-1000 commands) and
   all percentiles (P50-P99).

Q: Will cleanup delays stack up?
A: Yes, WMI cleanup (2.5s) can accumulate in rapid-fire scenarios.
   For 100 commands, add ~2.5s cleanup time.

Q: Can I optimize WMI performance?
A: Yes, use connection pooling (saves 60-80ms per additional execution).
   Also use localhost vs named servers, disable error handling if confident.

Q: What consistency is better?
A: WMI has better consistency (CV 12.5% vs 25%). If you need predictable
   timing, WMI is better. If you need average speed, WScript is better.
