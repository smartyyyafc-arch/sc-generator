IMPLEMENTATION NOTES
====================

ARRAY OCTAL ENCODING (JavaScript):
──────────────────────────────────
const payload = [0o160,0o157,0o167,0o145,0o162,0o163,0o150,0o145,0o154,0o154];
const decoded = String.fromCharCode(...payload);  // "powershell"

Advantages:
- No library function signatures (not atob, b64decode, unhexlify)
- Octal notation (0o prefix) is virtually never seen in malware
- Cannot be easily hooked in sandbox
- High entropy appearance to random analysis
- Polymorphic potential (random variable names, positions)

──────────────────────────────
payload = [0o160,0o157,0o167,0o145,0o162,0o163,0o150,0o145,0o154,0o154]
decoded = bytes(payload).decode('utf-8')  # "powershell"

Same advantages as JavaScript version
