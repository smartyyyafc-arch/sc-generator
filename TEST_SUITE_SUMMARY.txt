================================================================================
TROUBLESHOOTING GUIDE
================================================================================

SLOW TEST EXECUTION
Problem: Tests running slowly
Solution: Use SHA256 instead of SHA512 (faster hashing)

HIGH COLLISION RATE
Problem: Hash collisions detected
Solution: Review fingerprint serialization, ensure all attributes included

VM DETECTION FAILURE
Problem: VMs not detected properly
Solution: Check user-agent formatting and VM indicator patterns

LOCALE TEST FAILURES
Problem: Locale tests failing
Solution: Verify system timezone database is up-to-date

OUT OF MEMORY
Problem: Memory exhaustion on fingerprint tests
Solution: Reduce uniqueness test size from 1000 to 100
