PERFORMANCE CHARACTERISTICS
================================================================================

Encoding Time: O(n) where n = input length
  - Linear traversal through input
  - Each character processed once per layer
  - No redundant operations

Decoding Time: O(n) where n = encoded data size
  - Linear traversal through encoded data
  - Each pair/element processed once per layer
  - No redundant operations

Memory Usage:
  - Base64: ~1.33× original (33% expansion)
  - Hex: 2× Base64 (100% expansion)
  - Array: Same as Hex (each 2-char pair becomes 1 array element)

Space Efficiency:
  - Final encoding (Array format) is smallest viable
  - Hex intermediate form is larger but necessary
  - Base64 provides UTF-8 to ASCII safety
