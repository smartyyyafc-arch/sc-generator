XOR

CONFIGURATION OPTIONS
=====================

encoding_method
  - BASE64 (default)
  - HEX
  - XOR
  - ARRAY
  - NESTED
  - POLYMORPH

variable_obfuscation
  - Randomize variable names

obfuscation_level
  - 1-5 scale

randomize_names
  - True: random names (secure)
  - False: numbered names (fast)

chunk_size
  - For ARRAY method
  - Default: 16 bytes

xor_key
  - Custom XOR key (optional)
  - Auto-derived if None
