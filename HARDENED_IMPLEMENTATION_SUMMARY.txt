ARCHITECTURE OVERVIEW
================================================================================

Three-Layer Encoding Pipeline:
┌──────────────────┐
│  Original Data   │
└────────┬─────────┘
         │
         ▼
┌──────────────────────────────────────────────┐
│ Layer 1: Base64 + HMAC-SHA256 Verification  │
│ Format: CHECKSUM|BASE64_DATA                │
│ Security: Integrity checking, tamper detection
└────────┬─────────────────────────────────────┘
         │
         ▼
┌───────────────────────────────────────────────────────────┐
│ Layer 2: Polymorphic Hex Encoding (4 Variants)          │
│ Format: V{VAR}|CHECKSUM|ENCODED_HEX                     │
│ Variants:                                                 │
│   - Variant 0: Nibble bit inversion (XOR 0xF)           │
│   - Variant 1: Interleaved padding (random)             │
│   - Variant 2: Reversed with additive offset            │
│   - Variant 3: XOR-masked with random key               │
│ Security: 4 × 256 = 1024 encoding combinations          │
└────────┬──────────────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────────────────────────┐
│ Layer 3: Array Shuffling with Position Tracking          │
│ Format: V#|L2CHKSUM|L3CHKSUM|SHUFFLED_DATA|POSITION_MAP │
│ Security: ~n! permutation complexity + HMAC verification │
└────────┬─────────────────────────────────────────────────┘
         │
         ▼
┌──────────────────┐
│ Encoded Payload  │
└──────────────────┘

Per-Layer Security:

Layer 1:
  ✓ HMAC-SHA256 with per-instance 16-byte random key
  ✓ Checksum verification (tamper detection)
  ✓ Format validation with separator-based parsing
  ✓ Base64 encoding for binary-safe representation

Layer 2:
  ✓ 4 polymorphic encoding variants
  ✓ Random variant selection per instance
  ✓ Random XOR key (0-255 range)
  ✓ HMAC-SHA256 checksum of original hex
  ✓ Variant marker for automatic detection
  ✓ 1024 total encoding combinations

Layer 3:
  ✓ Random shuffle permutation per instance
  ✓ Position map for exact reconstruction
  ✓ HMAC-SHA256 checksum of original array
  ✓ Preservation of Layer 2 metadata
  ✓ Prevents isolation attacks

Cross-Layer:
  ✓ Layer binding prevents bypass
  ✓ Cascading failures on tampering
  ✓ Format validation at each layer
  ✓ Three independent checksum verifications

================================================================================
ATTACK RESISTANCE ANALYSIS
================================================================================

Automated Decoding Tools:
  ❌ Signature-based detection - FAILS
     - No fixed signatures due to polymorphic variants
     - Random keys and shuffle patterns unique per instance
  
  ❌ Pattern recognition - FAILS
     - Layer 2 polymorphism defeats pattern matching
     - Layer 3 shuffling disrupts sequential patterns
  
  ❌ Brute force - FAILS
     - 4 variants × 256 XOR keys = 1024 Layer 2 combinations
     - Layer 3 shuffle requires ~n! permutations to test
     - HMAC-SHA256 provides 128-bit strength

Layer Isolation Attacks:
  ❌ Cannot bypass Layer 1 - FAILS
     - Each layer has cryptographic integrity checks
     - Checksum validation prevents unauthorized decoding
  
  ❌ Cannot extract Layer 2 in isolation - FAILS
     - Layer 3 checksum doesn't match if separated
     - Variant selection is random and per-instance
  
  ❌ Cannot use decoders in isolation - FAILS
     - Layer dependencies prevent standalone operation
     - Cross-layer verification prevents bypass

Manual Reverse Engineering:
  ✓ Possible: Identifying overall layer structure
     - Format separators (|) are visible
     - Layer structure can be identified
  
  ✓ Difficult: Extracting variant
     - Variant marker visible in Layer 2 output
     - Still requires knowing XOR key (0-255)
  
  ✓ Very Difficult: Testing hypotheses
     - HMAC verification prevents trial-and-error
     - Produces error on wrong variant/key combination
  
  ✓ Impossible: Building reusable dictionary
     - Per-instance random keys prevent reuse
     - Unique shuffle per instance
     - Layer 1 per-instance key generation

================================================================================
PERFORMANCE CHARACTERISTICS
================================================================================

Encoding Overhead:
  - Layer 1: +33% (Base64 expansion)
  - Layer 2 Variant 0: 0% (transformation)
  - Layer 2 Variant 1: +100% (interleaved padding)
  - Layer 2 Variant 2: 0% (transformation)
  - Layer 2 Variant 3: 0% (transformation)
  - Layer 3: +5% (position map metadata)

Expected Sizes:
  - Small payload (10 chars): ~50-100 bytes encoded
  - Medium payload (100 chars): ~300-600 bytes encoded
  - Large payload (1000 chars): ~2500-5000 bytes encoded

Time Complexity:
  - Encoding: O(n) linear in payload size
  - Decoding: O(n) linear in payload size
  - Variant selection: O(1) constant time
  - Shuffle: O(n) linear with one pass

Memory Usage:
  - O(n) temporary buffers during operation
  - No streaming support (entire payload buffered)
