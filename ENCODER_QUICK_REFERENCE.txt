================================================================================
CLASS METHODS REFERENCE
================================================================================

BASE64ENCODER CLASS
===================

encode_to_base64(text: str) -> str
  - Encode plain text to Base64
  - Input: Any string
  - Output: Base64-encoded string
  - Example: "Hello" -> "SGVsbG8="

encode_to_base64_with_cache(text: str) -> Tuple[str, str]
  - Encode with caching for repeated operations
  - Output: (encoded_string, cache_key)

encode_command_payload(command: str) -> str
  - Encode command for payload use
  - Convenience wrapper for encode_to_base64

encode_file_content(content: str) -> str
  - Encode file content to Base64
  - Convenience wrapper for encode_to_base64

encode_bytes_to_base64(data: bytes) -> str
  - Encode binary bytes to Base64
  - Input: bytes object
  - Raises TypeError if input is not bytes

create_vbs_encoded_variable(text: str, var_name: Optional[str]) -> str
  - Create VBS code with encoded variable
  - Output: VBS Dim statement with encoded value
  - Auto-generates variable name if not provided

create_vbs_decoder_pair(text: str) -> Tuple[str, str]
  - Create paired encoder-decoder VBS code
  - Output: (encoder_code, decoder_code)
  - Includes full MSXML2 decoder logic

create_powershell_encoded_command(command: str) -> str
  - Create PowerShell UTF-16LE encoded command
  - Use with: powershell.exe -EncodedCommand <output>

batch_encode_multiple(texts: list) -> dict
  - Encode multiple texts at once
  - Output: {original_text: encoded_text, ...}
  - Efficient for processing multiple payloads

verify_encoding(original: str, encoded: str) -> bool
  - Verify encoding correctness
  - Returns: True if encoding is valid, False otherwise

create_reverse_lookup_table(texts: list) -> dict
  - Create bidirectional lookup table
  - Output: {'forward': {}, 'reverse': {}}
  - Fast O(1) lookups in both directions

BASE64OPERATIONSPAIR CLASS
==========================

encode(text: str) -> str
  - Encode text to Base64
  - Wrapper method

decode(encoded: str) -> str
  - Decode Base64 to text
  - Raises ValueError if invalid Base64

encode_with_validation(text: str) -> str
  - Encode with verification
  - Validates result before returning

round_trip_transform(text: str) -> bool
  - Test encode-decode round trip
  - Returns True if successful

encodedCmd = "Y21kIC9jIGVjaG8gSGVsbG8="

With xmlDoc
    .LoadXML "<u><![CDATA[" & encodedCmd & "]]></u>"
    decodedCmd = .SelectSingleNode("u").text
End With
' decodedCmd = "cmd /c echo Hello"

----------------

================================================================================
ERROR HANDLING
================================================================================

TypeError: Invalid Input Type
---------- -----------------
# Problem: Trying to encode non-string
encoder.encode_to_base64(12345)
# Solution: Ensure input is string
encoder.encode_to_base64(str(12345))

ValueError: Invalid Base64 to Decode
---------- -----
# Problem: Decoding invalid Base64
ops.decode("Invalid!!!Base64")
# Solution: Use valid Base64 or handle exception
try:
    result = ops.decode(encoded)
except ValueError as e:
    print(f"Decode error: {e}")

================================================================================
PERFORMANCE TIPS
================================================================================

1. Use Caching for Repeated Encodings:
   encoded, key = encoder.encode_to_base64_with_cache(text)

2. Use Batch Operations for Multiple Texts:
   results = encoder.batch_encode_multiple(list_of_texts)

3. Use Lookup Tables for Frequent Lookups:
   lookup = encoder.create_reverse_lookup_table(texts)
   forward_result = lookup['forward'][text]
   reverse_result = lookup['reverse'][encoded_text]

4. Verify Once, Not Repeatedly:
   is_valid = encoder.verify_encoding(original, encoded)
