================================================================================
KEY FEATURES
================================================================================

RANDOM LAYER SELECTION
  - Automatically selects 1-3 layers
  - Each wrapper instance is unique
  - Optional seed for reproducibility
  - Customizable layer pool

ENCODING TYPES (8 Total)
  1. HEX             - Hexadecimal encoding
  2. BASE64          - Base64 encoding
  3. ROT13           - Rotation cipher
  4. XOR             - XOR with randomized key (1-255)
  5. OCTAL           - Octal representation
  6. ASCII           - ASCII code array
  7. REVERSE         - String reversal
  8. ZLIB            - Compression + base64

BIDIRECTIONAL OPERATIONS
  - encode()  - Apply all layers in sequence
  - decode()  - Reverse all layers in reverse order
  - Automatic verification that decode returns original

DECODER GENERATION
  - generate_decoder_python()     - Standalone Python code
  - generate_decoder_powershell() - Standalone PowerShell code
  - Self-contained, no external dependencies
  - Ready for deployment

INFO & REPORTING
  - get_layer_info()           - Layer configuration details
  - generate_wrapper_report()  - Detailed encoding report
