QUESTION: Why is Array Octal better than Base64?
ANSWER: Array Octal has 0.34 detection risk vs 0.79 for Base64.
        Octal (0o) notation is virtually never used in malware, so it has
        no standard detection signatures. Base64 has library functions
        (atob, b64decode) that are easily detected. Array Octal avoids
        all these detectable patterns.

QUESTION: What's the trade-off?
ANSWER: Array Octal is 75x slower than hex (13.64 µs vs 0.18 µs) and has
        509% size overhead (vs 33% for Base64). For evasion priority, this
        is acceptable. For speed-critical apps, use Hex.

QUESTION: Should I always use Array Octal?
ANSWER: Not necessarily. Use case matters:
        - Evasion priority: Array Octal (best)
        - Speed priority: Hex (0.18 µs)
        - Size priority: Base64 (33% overhead)
        - Balanced: Array Hex Escape (0.41 risk, 13.42 µs)

QUESTION: Can I use the Python framework to test new encodings?
ANSWER: Yes. The encoding_comparison.py file is a complete framework.
        You can extend the EncodingComparison class to add new encoding
        methods and detection vectors.
